# Guiones para grabar las 16 llamadas del demo

Tú haces de **cliente**. La recepcionista contesta sola con el nombre del negocio.
Las frases son una guía: dilas con tus palabras y responde a lo que ella pregunte.

## Antes de empezar

- **Audífonos con micrófono** (AirPods sirven). Con parlante se interrumpe con su propia voz.
- **Cuarto en silencio**: sin TV, música ni otras personas hablando.
- **Datos falsos siempre**: estas llamadas van a estar públicas en el sitio. Usa los nombres y
  teléfonos de cada guion (los números 555-01xx están reservados para ficción).
- **Duración ideal: 1½ a 2½ minutos.** Mínimo 20 segundos o el script la descarta.

## Cómo grabar cada una

1. Panel de Retell → **Agents** → abre el agente del guion (por ejemplo *Inmotion Demo · dental-es*).
2. **Test → Test Audio → Run Test**.
3. Espera a que ella salude. Habla natural, como un cliente real (un "eh" o una pausa está bien).
4. **Déjala terminar** cada frase antes de hablar.
5. Al final di que eso es todo y **deja que ella se despida y cuelgue**.
6. ¿Salió mal? Vuelve a grabar esa misma: el script toma la **última** llamada de cada agente.

Cuando termines (todas o algunas), avísale a Claude: corre `npm run recordings` y las mete al demo.
